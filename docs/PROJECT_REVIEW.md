# 项目检查与修复记录

检查日期：2026-09-13。范围：App、Core、全部内置模块、SwiftUI 界面、工程配置与 README。

## 已确认并修复的问题

| 问题 | 原实现的具体后果 | 修复方式 |
| --- | --- | --- |
| 命令超时失效 | 仅向父进程发送 SIGTERM；忽略信号的进程或持有管道的子进程使读取一直等待，输出无上限 | 独立进程组、硬超时、可取消执行、退出码/错误输出、每路输出上限 |
| 模块开关只影响显示 | 关闭后仍轮询媒体、系统与端口，自定义命令仍可能执行 | 协议增加 start/stop，注册表统一启停；关闭时取消任务并丢弃过期结果 |
| 自定义命令结果过期 | 执行中修改配置被 isRunning 忽略，删除的子项可能再次写回结果 | 配置变更取消旧批次，按版本与配置快照校验结果；区分成功无输出、失败和超时 |
| 媒体解析与并发错误 | 分隔符出现在标题中时解析失败；Spotify 毫秒被当秒；封面接口不匹配；慢查询排队且跨线程访问状态 | JXA JSON 元数据、按源归一化时长、Spotify URL / Music 原始封面数据、单次查询与版本校验、脚本子进程超时 |
| 音量脚本与交互竞争 | 默认启动也执行 AppleScript；轮询旧值可能覆盖拖动中的值 | CoreAudio 直接读取和设置输出设备，合并写入并丢弃旧读取；不支持的设备禁用对应控件 |
| 系统指标错误 | 网络字节差直接当作每秒速率；32 位计数不能表示多次回绕；CPU 无符号减法可能下溢；主线程执行采样 | 64 位网络快照和实际时间差，重置/唤醒重新建立基线，CPU 分项回绕差分，后台串行采样并释放 Mach host 端口 |
| 进程范围与终止校验不足 | lsof 未限定当前用户，按展示列解析；结束操作只依赖可能过期的 PID，失败没有反馈 | 当前用户 TCP LISTEN 过滤、lsof 字段协议；保留 UID 与启动时间，发信号前复核身份并显示错误 |
| 快捷键恢复与录制问题 | A 的键码 0 被当作未设置；无效持久值可能转换崩溃；窗口失焦后录制监听残留；录制事件继续传播；注册失败静默 | 区分不存在与零值、校验范围、组合键原子通知、录制结束清理并消费事件、显示注册错误 |
| 面板布局与屏幕选择不一致 | 多个常驻模块或长应用/命令列表超出固定窗口；失效标签选中状态不一致；仅使用 screens[0]，热区向上越界 | 面板统一滚动、固定底栏、有效标签回退、优先刘海屏并限制可见区域、热区使用同一屏幕且有上下边界 |
| 文档与实现脱节 | README 仍声称动态高度、五个模块及旧音量/网络实现 | 更新模块协议、固定窗口布局、权限时机和验证命令 |

## 验证

- 修改后 Debug、Release 构建及 21 项 XCTest 回归测试通过。
- 测试包含真实子进程超时/取消、大输出、继承管道、临时设置、模拟模块启停、实际 JXA 执行（模拟应用）、真实系统采样及临时本机监听端口扫描。

- `git diff --check` 通过。

## 验证边界

- 当前机器未安装 Spotify。Music / Spotify 的授权、真实曲目封面与播放控制尚未进行端到端验证；媒体测试覆盖脚本执行与数据解析。
- 音量读取已随应用启动验证，未为了测试改变用户当前音量；不同外接音频设备的写入行为需设备实测。
- 多显示器热区与窗口位置已校对代码，物理显示器重排、休眠恢复和全部音频硬件组合未逐一实测。
- 进程身份复核缩小 PID 复用风险；macOS 的身份查询和 kill 是独立系统调用，不能承诺完全消除两者之间的极小竞态。命令取消作用于本次创建的进程组，主动脱离该组的守护进程不在此机制覆盖范围内。
