# NotchDeck V1.0：全面插件化

版本号：1.0.0。V1.0 是从 0.x 系列进入 1.x 系列的大版本，以统一插件架构和独立插件市场作为新的起点。

## 主要变化

- 媒体、音量、应用、系统监控、进程监控、自定义和时钟全部成为随附插件，与订阅额度共用添加、移除、设置与生命周期管理。
- 首次升级自动登记原有组件，保留启用状态、布局、排序与配置；时钟仍默认关闭。移除后重启不会自动恢复，重新添加会启用并沿用配置。
- 官方市场迁入 [NotchDeck-Plugins](https://github.com/DeanWanghewei/NotchDeck-Plugins)，独立维护 manifest、生成目录、版本化脚本、使用文档与发布校验。
- 新仓库以 PR 与 CI 管理变更，校验目录格式、脚本哈希、不可覆盖的脚本地址和主应用正式安装包交付情况。
- 市场页面增加官方仓库入口，统一普通组件与订阅插件的状态和说明；时钟停用状态按组件默认配置正确显示。
- 客户端严格限定两个官方仓库的链接及脚本路径，下载前校验来源，拒绝路径穿越、编码绕过与外站来源。

## 升级与分发

Swift 插件仍随主应用编译和发布；适配脚本可通过市场独立更新。无需重新配置已有组件、账号或布局，不新增默认权限申请。

7 个原固定组件的插件化实现最低要求 NotchDeck 1.0.0。主仓库旧目录与脚本地址继续服务旧客户端。V1.0 正式安装包发布前，独立仓库公开目录仍只列出已交付的插件；安装包可下载后，再按发布流程同步新增条目，避免提前宣传未交付版本。

## 验证

全量逻辑测试覆盖配置迁移、安装/移除/重启、默认状态、目录兼容、来源白名单与脚本安全；界面通过深浅色 NSHostingView + cacheDisplay 自渲染检查。独立仓库通过目录工具测试、脚本语法检查及正式安装包对照校验。

本说明随 V1.0 提交维护；正式安装包是否已发布，以 [GitHub Releases](https://github.com/DeanWanghewei/NotchDeck/releases) 为准。
